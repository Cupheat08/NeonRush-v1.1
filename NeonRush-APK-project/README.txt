1. Create a free GitHub account and a new empty repository.
2. Upload ALL files of this folder (keep the .github folder) via "Add file -> Upload files".
3. Open the "Actions" tab -> "Build APK" -> wait ~5 minutes until it turns green.
4. Open the finished run -> Artifacts -> NeonRush-apk -> download, unzip, get app-debug.apk.
5. Send the APK to your phone, allow "install unknown apps", install.
